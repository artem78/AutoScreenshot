Замечания для пользователей Linux

После распаквки zip-архива нужно добавить флаг исполнения файлу AutoScreenshot

chmod +x AutoScreenshot

Для возможности сохранения в формат avif необходимо установить пакет libavif-dev

sudo apt install libavif-dev

При наличии ошибки "Could not initialize OpenSSL library" выполнить

sudo apt install libssl-dev
